FTG-Ausbildungsplanung
Fahrschulteam Thorsten Gels

Netlify: GitHub-Repository verbinden, Branch main, kein Build-Befehl, Publish directory .

Die App arbeitet ohne Backend. Entwuerfe, Themenablagen und Formatierungen werden ausschliesslich im Browser des jeweiligen Nutzers gespeichert. Es gibt keine gemeinsame Online-Datenbank. Browserdaten koennen geloescht werden: persoenliche Komplettsicherungen regelmaessig als Datei speichern. JSON-Sicherungen niemals in dieses oeffentliche Repository hochladen.

Windows: Edge oder Chrome. iPad: Safari, Teilen, Zum Home-Bildschirm.
Automatische Dateisicherung am PC: Sicherungsordner pro Sitzung verbinden. iPad: Alles als Datei sichern.
Kein garantierter Offline-Modus.
